## Wiring Diagram

| Component | Arduino Pin | Description |
| :--- | :--- | :--- |
| **Blue Button (Dot)** | **Pin 2** | One leg to Pin 2, other leg to **GND** |
| **Red Button (Dash)** | **Pin 3** | One leg to Pin 3, other leg to **GND** |
| **Buzzer (+)** | **Pin 8** | Long leg to Pin 8, short leg to **GND** |
| **I2C LCD SDA** | **A4** | Data line |
| **I2C LCD SCL** | **A5** | Clock line |
| **I2C LCD VCC** | **5V** | Power |
| **I2C LCD GND** | **GND** | Ground |

---

## How to Play
1. The LCD will show a letter and its Morse code.
2. You have **2 seconds** to memorize it.
3. The code will disappear.
4. Use the buttons to type the correct Morse sequence!
